# Notes

Put hand-written context for a week in this folder and the next build shows it inside that week's entry.

- `YYYY-Www.md` is shown in both languages, e.g. `2026-W43.md`.
- `YYYY-Www.es.md` and `YYYY-Www.en.md` are shown only in that language (use both for a translated note).
- Any other file name is ignored (like this README).
- Basic Markdown works: paragraphs, `###` headings, lists, quotes, code, **bold**, *italic*, links. Raw HTML is shown as text.
- The week label is the ISO week, Monday to Sunday (UTC). A note for a week with no snapshot still gets its own entry.
